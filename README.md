# 2024 ~ 2026 台指期三大法人未平倉「合計」× 台股走勢疊加圖表與未來一年量化推演

本專案提供 **2024 年至 2026 年** 期間：
1. **三大法人臺指期未平倉口數「合計（總和）」**（自營商 + 投信 + 外資淨部位加總，非單一法人）
2. **台灣加權股價指數（台股大盤 TAIEX）**
兩者的**雙軸疊加走勢圖表**，並結合 **AI 產業發展、聯準會（Fed）利率政策、新台幣匯率、法人籌碼結構與歷史週期對稱性**，提供 **未來半年至 1 年（2026/10 ～ 2027/10）** 的三大劇本機率與四季完整推演。
